This is the Clemson starter edition of Unitree UI. Camera, control, voxels, and the onboard SLAM interface come from upstream. Their operation still needs verification on the lab robot.

  1. Join the Go2 Wi-Fi hotspot on Windows 11. Close other robot clients.
  2. Set the Robot IP address (Go2 hotspot default: 192.168.12.1), enter the assigned AES key, and click Connect and open web view. The camera/voxel view opens after validation.
  3. First check connection, camera, status, and voxels with the robot stationary. Keep the paired remote ready before any supervised motion test.

Test the webcam panel

Run the local Python preview service in the go2wifi environment, then open the dashboard side panel. Tracking starts automatically. It shows extracted hand skeletons, gesture label, and velocity intent, without webcam video. Robot control starts disabled. After a supervised setup check, click Enable gesture control directly. No startup pose is required; fresh frames and the consistency hold still gate movement.
